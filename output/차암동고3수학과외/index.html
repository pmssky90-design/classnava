문제별 시작 시간과 종료 시간을 적기

시험이 끝난 뒤 기억에 의존하면 실제보다 오래 걸린 문제나 짧게 느껴진 문제를 정확히 구분하기 어렵습니다. 문제를 푼 순서와 함께 시작 시각, 답을 결정한 시각, 다시 검토한 시각을 간단히 표시해 보세요.

  • 문제에 처음 접근한 시간
  • 답을 적고 다음 문제로 넘어간 시간
  • 다시 돌아와 검토한 시간
  • 끝까지 풀지 못하고 보류한 시간

초 단위까지 적을 필요는 없습니다. 문제 번호 옆에 3분, 7분, 10분처럼 분 단위로 기록하면 충분합니다.

맞힌 문제도 시간 기록에 포함하기

맞혔다는 이유만으로 효율적으로 푼 문제라고 판단해서는 안 됩니다. 정답은 맞혔지만 풀이가 지나치게 길었거나 답을 여러 번 바꾼 문제라면 실전에서 위험 요소가 될 수 있습니다.

따라서 채점할 때 문제를 다음처럼 구분해 보세요.

  • 빠르고 확실하게 맞힌 문제
  • 오래 고민했지만 맞힌 문제
  • 찍거나 운 좋게 맞힌 문제
  • 시간 부족으로 풀지 못한 문제
  • 개념이나 접근 방법을 몰라 시작하지 못한 문제

이렇게 나누면 점수에 드러나지 않는 불안정한 문제를 찾을 수 있습니다.

시간이 부족해진 원인을 따로 기록하기

전체 시험 시간이 부족했다면 단순히 “시간 관리 실패”라고 적지 말고 어느 구간에서 시간이 줄었는지 확인해야 합니다. 앞부분의 기본 문제에서 계산이 길어졌는지, 한 문제를 보류하지 못했는지, 뒤쪽 문제에 처음부터 너무 오래 머물렀는지를 구분합니다.

특히 한 문제에 사용한 시간이 길었다면 다음 세 가지를 적어 보세요.

  • 조건을 식이나 그림으로 정리했는가?
  • 처음 접근이 막힌 뒤 다른 방법을 시도했는가?
  • 계속 생각해도 진전이 없을 때 문제를 보류했는가?

세 질문에 모두 부정적으로 답했다면 해당 문제는 실력보다 판단과 운영의 문제일 가능성이 큽니다.

기록은 분석으로 끝내지 말고 다음 시험의 행동으로 연결해야 합니다. 예를 들어 앞부분 계산에 시간이 오래 걸렸다면 풀이 속도를 무작정 높이기보다 계산 과정을 줄일 수 있는지 확인합니다. 한 문제에 지나치게 오래 머물렀다면 일정 시간 안에 핵심 조건을 식으로 만들지 못할 때 표시하고 넘어가는 기준을 정합니다.

시간 기록을 누적해서 비교하기
