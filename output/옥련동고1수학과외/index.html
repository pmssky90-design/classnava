옥련동고1수학과외 학습에서도 확인되지 않은 학교별 경향을 단정하지 않고, 학생이 실제로 받은 자료와 풀이 기록을 기준으로 현재 문제를 점검하는 것이 중요합니다.

경우의 수 문제에서 답이 실제보다 크게 나오는 대표적인 이유는 같은 대상을 서로 다른 경우로 두 번 세는 것입니다. 학생은 각각의 선택 과정을 빠짐없이 적었다고 생각하지만, 선택 순서만 달라졌을 뿐 결과는 같은 경우일 수 있습니다. 고1 수학에서는 문제의 조건을 읽고 경우를 나누는 과정이 중요하므로, 공식을 바로 적용하기보다 무엇을 하나의 결과로 볼 것인지 먼저 정해야 합니다.

중복 계산은 왜 생길까

예를 들어 세 명 중 두 명을 뽑는 상황에서 민수와 지수를 선택한 경우를 생각해 보겠습니다. 민수부터 고른 경우와 지수부터 고른 경우를 따로 기록하면 두 가지처럼 보이지만, 최종적으로 선택된 사람은 동일합니다. 이 문제에서 순서는 중요하지 않으므로 두 기록은 하나의 경우입니다.

반대로 회장과 부회장을 정하는 상황이라면 민수가 회장이고 지수가 부회장인 경우와 지수가 회장이고 민수가 부회장인 경우는 서로 다릅니다. 같은 두 사람을 선택했더라도 역할이 다르기 때문입니다. 따라서 중복을 막으려면 계산 전에 “선택된 대상만 중요한가, 선택 순서나 역할도 결과에 포함되는가”를 확인해야 합니다.

문제를 읽을 때 결과의 기준부터 정하기

문제를 보자마자 순열이나 조합 공식을 찾기보다, 답으로 세어야 하는 결과를 문장으로 바꾸어 보세요. “누가 뽑혔는가”를 묻는다면 선택된 구성만 비교합니다. “몇 번째에 뽑혔는가”, “어느 자리에 앉았는가”, “누가 어떤 역할을 맡았는가”를 묻는다면 순서나 위치가 결과에 포함됩니다.

이 기준을 짧게 표시하는 것도 도움이 됩니다.

  • 사람을 단순히 선택한다면 순서 없음
  • 등수나 자리를 정한다면 순서 있음
  • 회장, 부회장처럼 역할이 다르면 역할 구분
  • 같은 물건을 여러 번 선택할 수 있다면 중복 선택 여부 확인

이렇게 결과의 기준을 먼저 정하면 “두 번 뽑힌 것처럼 보이는 기록”이 실제로 다른 경우인지 판단하기 쉬워집니다.

경우를 직접 나눌 때는 겹치지 않게 만들기

조건이 있는 경우의 수 문제에서는 경우를 나누는 기준이 서로 겹치지 않아야 합니다. 예를 들어 학생을 남학생과 여학생으로 나누는 것은 한 사람이 동시에 두 범주에 속하지 않는다면 중복되지 않습니다. 하지만 “민수가 포함된 경우”와 “지수가 포함된 경우”처럼 나누면 민수와 지수가 모두 포함된 경우가 두 범주에 들어갈 수 있습니다.

이때는 한 기준만 사용해 경우를 나누는 편이 안전합니다. 먼저 민수가 포함되는 경우와 포함되지 않는 경우로 나눈 뒤, 각 경우 안에서 지수의 포함 여부를 살필 수 있습니다. 또는 선택된 사람 중 가장 작은 번호의 사람이 누구인지처럼 하나의 기준을 정해도 됩니다. 중요한 것은 어떤 결과도 두 범주에 동시에 들어가지 않도록 하는 것입니다.

표와 나열을 활용해 중복 확인하기

간단한 문제라면 가능한 결과를 직접 나열해 보는 것이 좋습니다. 네 명 A, B, C, D 중 두 명을 순서 없이 고른다면 AB, AC, AD, BC, BD, CD처럼 일정한 순서로 적습니다. BA, CA처럼 앞에서 이미 적은 조합은 다시 쓰지 않습니다.

나열할 때는 첫 번째 대상의 기준을 정해 보세요. A가 포함된 경우를 먼저 모두 적고, 그다음 A는 제외하고 B가 포함된 경우를 적는 방식입니다. 그러면 AB를 적은 뒤 BA를 다시 적는 실수를 줄일 수 있습니다. 인원이 많아 직접 나열하기 어렵다면 이 과정을 조합의 계산으로 바꾸되, 나열에서 확인한 “순서를 구분하지 않는다”는 의미는 그대로 유지해야 합니다.

공식을 사용하기 전 점검할 질문

순열과 조합을 구분하지 못해 중복이 생기는 학생은 공식 자체보다 문제의 대상과 결과를 연결하는 데 어려움을 겪는 경우가 많습니다. 다음 질문을 풀이 첫 줄 옆에 적어 보세요.

  • 한 번 정한 결과를 순서를 바꾸어 다시 적으면 다른 결과인가?
  • 자리를 바꾸거나 역할을 바꾸면 결과가 달라지는가?
  • 같은 대상을 반복해서 선택할 수 있는가?
  • 경우를 나눈 기준이 서로 겹치지는 않는가?
  • 각 결과가 정확히 한 번만 세어졌는가?

첫 번째 질문의 답이 아니오라면 순서를 고려하지 않는 방식이 필요할 가능성이 큽니다. 반대로 역할이나 위치가 달라질 때 결과도 달라진다면 단순히 사람의 묶음만 세어서는 안 됩니다.

답이 해설과 다를 때 “계산을 잘못했다”고 바로 결론 내리지 마세요. 자신이 센 결과를 실제로 펼쳐 놓고 어떤 항목이 반복되었는지 확인해야 합니다. AB와 BA를 모두 적었는지, 특정 조건에 해당하는 항목을 두 경우에 동시에 넣었는지, 반대로 하나의 경우를 빠뜨렸는지를 구분합니다.

오답 노트에는 정답 공식만 옮기기보다 중복이 발생한 지점을 한 문장으로 남기는 것이 효과적입니다. 예를 들어 “두 사람의 선택만 묻는 문제에서 뽑는 순서를 별개의 경우로 셌다” 또는 “경우를 나눈 기준이 겹쳐 공통 조건을 두 번 세었다”처럼 작성합니다. 다음 문제를 풀 때 같은 실수를 미리 경고하는 기준이 되기 때문입니다.
