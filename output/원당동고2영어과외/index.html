원당동 고2영어과외 영어 서술형에서 문제의 요구 조건을 찾는 방법

원당동 고2영어과외 영어 서술형에서 문제의 요구 조건을 찾는 방법 페이지입니다. 현재 학습 상태를 점검하고 시험 준비 순서를 세우는 방법을 안내합니다.

영어 서술형에서 감점되는 이유가 항상 문법 실수인 것은 아닙니다. 문장을 어느 정도 만들 수 있어도 문제에서 요구한 내용을 빠뜨리거나, 제시된 조건과 다른 형태로 답을 쓰면 점수를 얻기 어렵습니다. 특히 고2 서술형은 단순히 본문 문장을 그대로 옮기는 데서 끝나지 않고, 제시문·우리말 조건·주어진 단어를 함께 확인해야 하는 경우가 많습니다.

먼저 무엇을 써야 하는지 확인하기

답안을 작성하기 전에 문제의 요구를 한 문장으로 바꾸어 말해보는 과정이 필요합니다. 예를 들어 “다음 내용을 영어로 쓰시오”라는 문제라면 핵심 내용만 옮기면 되는지, 특정 단어를 반드시 사용해야 하는지, 주어진 어휘를 변형할 수 있는지 확인해야 합니다. “두 문장으로 쓰시오”, “주어진 단어를 모두 사용하시오”, “필요하면 형태를 바꾸시오”와 같은 조건도 답안의 일부입니다.

문제에서 요구하는 행동을 먼저 표시하면 좋습니다. 설명하라는 것인지, 비교하라는 것인지, 이유를 쓰라는 것인지에 따라 문장의 방향이 달라지기 때문입니다. 이유를 묻는데 사실만 적거나, 두 대상을 비교하라는 문제에서 한쪽의 특징만 쓰면 문법적으로 완성된 문장도 정답이 되기 어렵습니다.

조건을 내용 조건과 형식 조건으로 나누기

서술형 문제의 조건은 크게 두 종류로 나눌 수 있습니다. 내용 조건은 반드시 포함해야 하는 정보입니다. 누가 무엇을 했는지, 어떤 이유가 있는지, 결과가 무엇인지와 같은 핵심 내용이 여기에 해당합니다. 형식 조건은 문장의 개수, 사용해야 할 단어, 시제, 부정 표현, 비교 표현처럼 답안을 구성하는 방식입니다.

예를 들어 “환경 보호를 위해 학생들이 할 수 있는 일을 두 가지 쓰고, given 단어를 사용하시오”라는 문제라면 환경 보호라는 주제만 언급해서는 부족합니다. 학생들이 할 수 있는 행동이 두 가지 들어가야 하고, 제시된 단어도 빠지지 않아야 합니다. 답을 쓴 뒤에는 ‘요구된 내용이 모두 들어갔는가’와 ‘지시된 형식을 지켰는가’를 따로 확인해야 합니다.

주어진 단어는 먼저 역할을 정하기

주어진 단어를 문장에 억지로 끼워 넣으면 어순이나 문법이 흔들릴 수 있습니다. 단어를 보기 전에 우리말 조건에서 주어, 동작, 대상, 이유를 먼저 정리해보세요. 그다음 주어진 단어가 문장에서 주어로 쓰이는지, 동사로 쓰이는지, 목적어나 수식어로 쓰이는지 결정합니다.

동사가 제시되어 있다면 시제와 주어에 맞게 형태를 바꿔야 하는지도 확인해야 합니다. 명사가 복수로 필요한지, 동명사나 부정사가 자연스러운지, 수동태가 필요한 상황인지도 문장의 의미를 만든 뒤 판단하는 편이 안전합니다. 단어를 모두 사용했다는 사실만으로 충분하지 않고, 문장 안에서 올바른 역할을 하고 있어야 합니다.

처음부터 긴 문장을 완성하려고 하면 조건 하나를 놓치기 쉽습니다. 먼저 주어와 핵심 동사를 정하고, 문제에서 요구한 내용을 목적어 또는 보충 설명으로 붙여보세요. 이유를 나타내야 한다면 핵심 문장을 만든 뒤 because나 so that 같은 연결 표현을 선택할 수 있습니다. 두 내용을 대조해야 한다면 but이나 while이 필요한지 살펴봅니다.

이때 우리말 어순을 그대로 영어로 옮기지 않는 것이 중요합니다. 영어 문장의 중심 구조를 먼저 세운 뒤 세부 정보를 추가해야 문장이 길어져도 흐트러지지 않습니다. 특히 고2 서술형에서는 관계대명사, 분사, 접속사 등이 포함된 문장을 요구할 수 있으므로, 수식어를 넣기 전에 무엇을 꾸미는지 확인해야 합니다.

완성 후에는 ‘문법’보다 ‘요구 조건’을 먼저 점검하기

답안을 다 쓴 뒤 많은 학생은 철자나 동사 형태부터 확인합니다. 물론 필요한 과정이지만, 그보다 먼저 문제의 조건을 다시 읽어야 합니다. 요구한 행동을 모두 썼는지, 내용의 순서가 바뀌지 않았는지, 정해진 문장 수를 지켰는지부터 확인하세요.

틀린 답을 고칠 때도 완성된 모범 답안을 그대로 외우기보다 어떤 조건을 놓쳤는지 기록하는 것이 좋습니다. 내용 누락인지, 단어 사용 문제인지, 문장 수나 시제 오류인지 구분해야 다음 문제에서 같은 실수를 줄일 수 있습니다. 한 문제를 다시 쓸 때는 해설을 본 뒤 바로 베끼지 말고, 조건만 확인한 상태에서 스스로 재작성해보세요.

영어 서술형은 영어를 잘 아는 것뿐 아니라 문제의 지시를 정확히 읽고 답안으로 옮기는 능력까지 요구합니다. 원당동고2영어과외에서도 문장을 만들기 전 요구 조건을 분리하고, 작성 후에는 조건과 표현을 순서대로 점검하는 습관을 중심으로 연습하면 불필요한 감점을 줄일 수 있습니다.
