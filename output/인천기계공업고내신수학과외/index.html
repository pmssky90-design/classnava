많이 풀었지만 실제로는 같은 문제만 푼 경우

문제집의 진도가 빠르면 스스로 충분히 공부했다고 느끼기 쉽습니다. 그러나 비슷한 형태의 기본 문제를 연속해서 풀면 다음에 사용할 공식이나 풀이 순서가 눈에 보이는 상태에서 답을 찾게 됩니다. 이때는 문제를 해결한 것처럼 보여도, 숫자나 조건의 위치가 바뀌거나 질문 방식이 달라지면 첫 식을 세우지 못할 수 있습니다.

확인 방법은 간단합니다. 한 유형을 여러 문제 풀었다면 그중 일부를 표시해 두고 하루나 이틀 뒤 풀이를 가린 채 다시 시작해 보세요. 답을 기억하는지가 아니라 문제의 조건을 읽고 왜 그 방법을 선택했는지를 설명할 수 있어야 합니다. 풀이 첫 줄이 바로 나오지 않는다면 문제 수를 더 늘리기보다, 문제에서 주어진 정보와 구해야 할 값을 연결하는 연습이 먼저입니다.

공부 시간이 오답을 줄이는 데 사용되지 않은 경우

오답을 볼 때는 정답 풀이를 먼저 베껴 쓰지 말고 자신의 풀이에서 처음 잘못된 부분을 찾으세요. 개념을 몰랐다면 관련 설명과 대표 문제를 짧게 확인하고, 조건을 놓쳤다면 문제에서 중요한 정보를 표시한 뒤 같은 문제를 다시 읽습니다. 계산에서 틀렸다면 전체 풀이를 처음부터 반복하기보다 부호, 괄호, 분수, 식을 옮기는 과정 중 어느 지점에서 오류가 생겼는지 확인합니다. 문제 번호와 첫 오류, 다시 풀 날짜만 남겨도 오답 관리가 훨씬 구체적으로 바뀝니다.

맞힌 문제를 실력으로 착각하는 경우

정답을 맞혔다고 해서 항상 안정적으로 이해한 것은 아닙니다. 해설을 본 직후 풀었거나, 풀이 과정은 설명하지 못하지만 답만 맞혔거나, 오랜 시간 고민한 끝에 우연히 해결한 문제라면 시험에서 다시 막힐 가능성이 있습니다. 특히 시험에서는 문제를 처음 봤을 때 어떤 정보부터 사용할지 결정하는 시간이 필요하므로, 맞힌 문제 중에서도 풀이 근거가 불분명한 문제를 따로 확인해야 합니다.

재확인할 문제는 전부 고를 필요가 없습니다. 풀이 시간이 지나치게 길었던 문제, 답을 고쳤던 문제, 해설의 첫 단계를 따라 한 문제만 골라 문제만 보고 다시 풀어 보세요. 풀이를 끝낸 뒤에는 ‘왜 이 식을 세웠는가’, ‘다른 조건이 추가되면 어느 부분이 달라지는가’를 짧게 말해 봅니다. 이 과정을 통과하지 못한 문제는 새로운 문제를 더 푸는 것보다 우선순위가 높습니다.
