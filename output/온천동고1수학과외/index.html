고1 경우의수 문제에서 막히는 학생들은 계산을 못해서가 아니라, 문제 전체를 한 번에 처리하려는 경우가 많습니다. 조건이 두세 개만 붙어도 선택 대상, 순서, 중복 여부를 동시에 판단해야 하므로 어디서부터 세어야 할지 모호해집니다. 이때 필요한 것은 무작정 공식을 고르는 능력이 아니라 복잡한 상황을 서로 겹치지 않는 작은 경우로 나누는 습관입니다.

왜 한 번에 세려고 하면 어려워질까

예를 들어 여러 명 중 일부를 뽑아 특정 자리에 배치하고, 특정 학생은 반드시 포함하거나 서로 이웃하지 않아야 한다고 해 보겠습니다. 문제를 읽자마자 전체 인원을 기준으로 순열이나 조합을 적용하면 조건이 빠질 가능성이 큽니다. 순서를 고려해야 하는 단계와 선택만 하는 단계를 구분하지 못하고, 한 번 센 경우를 다시 세거나 반대로 누락하기도 합니다.

특히 고1 경우의수에서는 한 문제 안에 선택, 배열, 조건 처리가 함께 등장합니다. 따라서 공식의 이름을 먼저 떠올리기보다 “무엇을 기준으로 나누면 각 경우의 특징이 분명해지는가”를 찾아야 합니다. 기준이 잘 정해지면 각각의 작은 경우에서는 사용할 계산이 단순해집니다.

가장 먼저 확인할 것은 분류 기준

경우를 나눌 때는 아무 기준이나 세우면 안 됩니다. 나눈 경우들이 서로 겹치지 않아야 하고, 전체 상황을 빠짐없이 포함해야 합니다. 학생이 자주 사용하는 기준은 특정 대상의 포함 여부입니다. 예를 들어 A가 선택되는 경우와 선택되지 않는 경우로 나누면 두 경우가 겹치지 않습니다.

자리 배치 문제라면 특정 사람이 첫 번째 자리에 있는지, 가운데 자리에 있는지, 어느 쪽에도 없는지를 기준으로 삼을 수 있습니다. 숫자 만들기 문제라면 첫 자리의 숫자가 0인지 아닌지, 짝수인지 홀수인지처럼 이후 조건에 영향을 주는 항목을 기준으로 나눌 수 있습니다. 중요한 것은 계산하기 편한 기준이 아니라, 나눈 뒤 남은 조건을 분명하게 처리할 수 있는 기준을 선택하는 것입니다.

문제를 읽으며 조건을 표시하는 방법

문제를 보자마자 숫자를 곱하지 말고 조건을 짧게 표시해 보세요. ‘반드시 포함’, ‘포함하지 않음’, ‘이웃하지 않음’, ‘순서를 고려함’, ‘중복 허용’처럼 계산에 직접 영향을 주는 표현에 표시합니다. 그다음 각 조건이 선택 단계에 영향을 주는지, 배열 단계에 영향을 주는지 구분합니다.

예를 들어 5명 중 3명을 뽑아 순서대로 세우는 문제에서 A가 반드시 포함된다고 해 보겠습니다. 먼저 A의 포함 여부를 나눌 필요는 없습니다. 이미 반드시 포함이라는 조건이 정해졌기 때문입니다. A가 차지할 자리를 정한 뒤 나머지 두 자리를 채우는 방식이 자연스럽습니다. 반대로 A가 포함될 수도 있고 포함되지 않을 수도 있다면, 두 상황을 나누어 각각 계산한 뒤 더해야 합니다.

더하는 경우와 곱하는 경우를 구분하기

경우를 나눈 뒤에는 각 경우의 결과를 더합니다. ‘A가 포함되는 경우’와 ‘A가 포함되지 않는 경우’처럼 동시에 일어날 수 없는 상황을 나누었기 때문입니다. 반면 하나의 경우 안에서 여러 단계를 차례로 진행한다면 각 단계의 수를 곱합니다. 먼저 학생을 선택하고, 선택한 학생을 배치하는 상황이 이에 해당합니다.

학생들이 자주 하는 실수는 경우를 나누어 놓고 곱하는 것입니다. 또는 실제로는 순서대로 진행되는 선택인데 단순히 더하기도 합니다. 식을 세운 뒤 “이 두 상황은 동시에 가능한가?”라고 물어보면 판단에 도움이 됩니다. 동시에 일어날 수 없는 분류라면 더하고, 하나의 결과를 만들기 위해 연속으로 해야 하는 선택이라면 곱합니다.

작은 예로 나눈 뒤 일반 문제에 적용하기

복잡한 문제를 바로 해결하기 어렵다면 조건을 하나 줄인 작은 상황을 먼저 만들어 보세요. 예를 들어 6명을 배열하는 문제에서 특정 두 사람이 이웃하지 않아야 한다면, 먼저 전체 배열에서 두 사람이 이웃하는 경우를 어떻게 셀 수 있는지 살펴볼 수 있습니다. 두 사람을 하나의 묶음처럼 생각하면 전체 구조가 단순해집니다.

또 다른 방법은 실제 대상을 기호로 바꾸어 표를 만드는 것입니다. A가 포함되는 경우와 제외되는 경우, 첫 자리가 홀수인 경우와 짝수인 경우를 행으로 나누고 각 칸에서 선택과 배열의 순서를 적습니다. 표를 작성하면 어떤 경우가 빠졌는지, 같은 경우를 두 번 계산했는지 확인하기 쉽습니다.

나눈 경우가 적절한지 검산하는 방법

계산이 끝났다면 답만 확인하지 말고 분류의 완전성을 점검해야 합니다. 첫째, 모든 가능한 상황이 어느 한 경우에 들어갔는지 확인합니다. 둘째, 하나의 상황이 두 분류에 동시에 들어가지는 않는지 살펴봅니다. 셋째, 조건을 만족하지 않는 결과가 계산에 포함되지 않았는지 확인합니다.

가능하다면 조건을 잠시 제거한 전체 경우의 수와 비교해 보는 것도 좋습니다. 예를 들어 특정 조건을 적용한 결과가 조건을 적용하지 않은 전체 경우보다 많다면 분류나 계산에 오류가 있는 것입니다. 작은 숫자로 직접 목록을 만들어 결과를 비교하는 방법도 개념을 점검하는 데 효과적입니다.
