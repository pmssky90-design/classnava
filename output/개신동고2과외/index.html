약한 과목의 단원은 독립적으로 끝나지 않는 경우가 많습니다. 앞에서 배운 개념을 이해해야 다음 내용을 따라갈 수 있기 때문에, 한 단원을 넘긴 채 현재 진도만 공부하면 수업 내용이 점점 낯설어집니다. 고1에서 배운 내용이 직접 연결될 때도 있지만, 반드시 고1 전체를 다시 공부해야 하는 것은 아닙니다. 지금 막히는 문제를 확인하고 그 문제를 푸는 데 필요한 개념만 찾아 보완하는 방식이 효율적입니다.

예를 들어 현재 단원의 문제를 풀다가 특정 공식이나 문법 개념에서 반복해서 막힌다면, 교과서와 수업 필기에서 해당 부분만 다시 확인합니다. 이후 비슷한 기본 문제를 몇 개 풀어 현재 진도를 계속 따라갈 수 있는지 점검해야 합니다.

후반에는 미룬 공부와 새 시험 범위가 겹친다

약한 과목을 미루는 학생이 먼저 확인할 것

  • 어느 단원에서 문제 풀이가 중단되는지 표시합니다.
  • 개념을 모르는지, 문제 조건을 해석하지 못하는지 구분합니다.
  • 해설을 읽은 뒤 도움 없이 같은 유형을 다시 풀어봅니다.
  • 한 문제에 지나치게 오래 머문다면 표시하고 다음 문제로 넘어갑니다.
  • 이번 주에 반드시 회복할 범위를 한두 가지로 제한합니다.

틀린 문제를 모두 모아 한꺼번에 해결하려 하면 다시 부담이 커집니다. 먼저 현재 수업과 시험 준비에 직접 영향을 주는 문제부터 골라야 합니다. 맞혔더라도 풀이 시간이 지나치게 길었거나 답을 우연히 선택한 문제는 안정적으로 이해한 것으로 보지 않는 것이 좋습니다.

처음부터 많은 양을 계획하기보다 다음 수업을 이해하는 데 필요한 개념 하나, 대표 문제 몇 개처럼 시작점을 작게 정하는 것이 좋습니다. 약한 과목을 완벽하게 끝내는 것이 목표가 아니라, 계속 미루던 과목이 현재 진도에서 더 밀리지 않도록 만드는 것이 우선입니다.

개신동고2과외는 학생의 실제 공부 기록을 바탕으로 어떤 과목이 단순히 어려운지, 어떤 과목이 반복적으로 뒤로 밀리는지를 구분하고 학습 순서를 조정하는 데 초점을 둘 수 있습니다. 학기 후반의 부담을 줄이려면 약한 과목을 몰아서 해결하려 하기보다, 현재 진도를 막는 부분부터 지금 조금씩 처리해야 합니다.
